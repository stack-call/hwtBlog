# 第 25 章：为什么不必为每个变量手写类型？

所有数据字段都有了类型，代码开始出现重复声明。我们已经知道 `100` 是整数，为什么局部变量还要再写一次相同信息？

## 显式标注在 API 边界上可读性很强

显式标注在 API 边界上可读性很强，尤其对多人协作和跨模块调用有帮助。但局部表达式通常已经暴露足够信息。

**教学实现：**

```python
amount: int = 100
rate: int = 90
result: int = amount * rate // 100
```

## 若每一步都重复同样的类型

若每一步都重复同样的类型，程序冗余增加，一旦表达式变更还要手工同步。我们希望编译器或类型检查工具从已知操作推导局部类型。

**用于触发限制的代码／输入（实验场景，不伪称来自框架）：**

```python
# 想象每个中间表达式都必须重复标注
x: int = 100
y: int = x + 20
z: int = y * 2
```

**因此需要的能力。** 通过字面量、运算符和上下文产生类型约束，自动推导尚未显式写出的类型。类型推断是减少标注的手段，不等于不进行类型检查。

## 把新机制落实成代码

**改进后的教学实现：**

```python
amount = 100
rate = 90
result = amount * rate // 100
# Python 运行时按对象类型执行；静态工具可推断它们的类型
```

在 Python 中赋值无需类型声明；静态检查工具可以从整数字面量推断许多局部类型。Rust、Go、C++ 等语言也有各自的局部类型推断机制，但约束能力和边界不同。

## 表达式 100 为整数类型

表达式 `100` 为整数类型，`rate` 同样取自整数，乘法与整数除法在当前操作中得到整数。类型关系可以自底向上传播；遇到泛型或重载时，可能需要从上下文反向约束。

## Rust 经常省略局部变量类型

Rust 经常省略局部变量类型，同时仍做编译期检查。

**Rust 示例（教学代码，非所引用仓库的源码节选）：**

```rust
let amount = 100_i64;
let rate = 90_i64;
let total = amount * rate / 100;
// total 的类型可由上下文推断为 i64
```

Rust 的数字字面量推断还涉及默认类型与上下文约束；Python 的整数对象表示和 Rust 固定宽度 i64 的溢出规则不同。

## 从一个漏写类型的变量开始

静态类型系统不一定要求每个变量都显式写类型。看 Rust：

```rust
let cents = 350_i64;
let total = cents + 100;
```

编译器可以从 `cents` 的类型及加法约束推断 `total` 类型。但如果没有上下文，某些表达式就无法唯一确定目标类型；更重要的是，推断是在求解一组约束，而不是运行程序猜测结果。

```rust
let xs: Vec<i64> = vec![100, 250];
let sum: i64 = xs.iter().sum();
```

`sum()` 本身可以服务多种结果类型，通过 `let sum: i64` 告诉编译器当前需要哪一种实现。Java 的 `var`、C++ 的 `auto`、Go 的 `:=`、Zig 的 `const x = ...` 与 Python 的动态绑定不能简单当成同一个类型推断算法。

要追的核心问题是“编译器从哪里获得约束”：字面量、运算符、函数参数、返回类型以及泛型界限。类型推断减少了重复声明，但不应让公共 API 的意图变得含糊。

## 对照规范和真实实现

**源码/规范阅读路线（供读者核对，并非声称已经逐行验证）：** [Rust Reference：Type inference](https://doc.rust-lang.org/reference/)。

查 Rust 类型推断与字面量规则，比较“类型被省略”与“类型未受约束”。源码层面可再看 rustc 类型检查管线，但本章只需要规范层证据。

## 实验：把 Rust 片段中的 rate 改为 90.0

把 Rust 片段中的 `rate` 改为 `90.0`，观察类型不匹配并思考如何显式转换；在 Python 中做同样改变观察结果类型。

**应当观察到（自行运行前属于预期）：** Rust 不会自动对 `i64` 与浮点数进行一般的混合算术转换，需明确处理；Python 的整数和浮点混算一般产生浮点结果。

## 边界：推断减少噪声

推断减少噪声，但复杂表达式可能让读者难以看出 API 意图。跨模块接口和有歧义的数值计算，显式标注往往更合适。

**跨语言迁移时，** C++ `auto`、Rust `let`、Go `:=`、Zig `const` 与 Python 隐式绑定都可减轻局部类型书写，但各自对泛型、字面量和隐式转换有不同规则。
