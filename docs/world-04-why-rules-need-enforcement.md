# 为什么人们需要规则？——从共同约定到监督、执行与权力约束

> **系列位置：** 第 4 层「社会基本机制」· 第 4 课  
> **本课只回答一个问题：** 为什么大家明明同意某个共同目标，仍然需要规则，以及保证规则有效的机制？  
> **上一课：** [从个人选择到社会互动——为什么合作与冲突会同时出现？](./world-03-from-individual-choice-to-social-interaction.md)  
> **系列引言：** [从根本理解世界：社会运行原理的总框架](./world-introduction.md)

上一课，我们已经从一个人的选择，走到了人与人之间的相互影响。

在一个**完全虚构的教学模型**中，20户家庭共用900升储水。大家希望保留100升作为应急储备，所以计划当天最多使用800升，即平均每户40升。但如果每户都额外取5升，原本计划留下的100升就会全部消失。

我们发现，问题未必在于大家不知道水有限，也未必在于人人都不关心他人。更棘手的是：**单户行动的好处与整个群体要承担的代价，可能不一致。**

现在，20户家庭终于坐在一起，作出一个共同决定：**「每户先按40升安排用水，大家一起保留100升应急水。」**

问题似乎解决了。

可是第二天，水池里又少了本应留下的水。

**既然已经达成约定，为什么结果还是不对？**

## 一、最简单的办法：大家口头约定、自觉遵守

先不要引入政府、法律、警察或者任何复杂制度。

对于20户家庭来说，最省事的方式就是互相提醒：

> 「今天每户用40升，特殊情况先跟大家说，尽量把100升留到明天。」

如果20户都愿意遵守，并且每户都知道其他人会遵守，这个办法**完全可能有效**。邻里关系、相互信任、共同责任感，确实能够支持合作。

但现在只改变一个条件：其中一户临时取走了45升，而不是40升。

这多出的5升究竟说明什么？

- 也许这户人家有特殊照护需要。
- 也许家里水桶漏水，取水记录出了问题。
- 也许他们以为「40升」只是建议。
- 也许他们知道规则，却决定偷偷多取。

这四种情况看上去都表现为「取水超过40升」，但性质完全不同。

**一句「大家要节水」还不够，因为它没有告诉我们：什么行为算遵守，什么情况算例外，发生争议时怎么办。**

于是，我们现在才需要引入第一个概念：**规则（rule）**。

规则不是一句抽象的好话，而是对**谁、在什么条件下、可以或不可以做什么**的相对明确的安排。

例如，我们可以把约定写得更清楚：

> 在今天这轮取水中，20户先各取40升；如果出现额外的必要用水需求，应先说明情况，由大家讨论如何调整安排，以尽可能保留100升应急水。

这仍然是一份**虚构的教学规则**，并非现实生活中的应急供水标准。它的作用，是把模糊的期待变成可以讨论、调整和判断的行为安排。

```text
共同目标：保留100升水
        │
        ▼
约定：每户先取40升
        │
        ▼
仍然可能有人超过约定
```

这个办法比单纯劝说前进了一步。不过，规则写清楚，并不等于事情就会照规则发生。

## 二、规则写清楚了，为什么还可能不起作用？

假设甲确实多取了5升，但甲说自己只取了40升。

其他19户无法直接看到甲家的水桶，水池里少掉的水也可能是漏掉的。

这里新出现的问题，不再是「大家有没有约定」，而是：**我们怎么知道实际发生了什么？**

在只有两户、每天面对面取水的小村庄，彼此看见取水过程，可能已经足够。可是人数增加后，监督成本也会上升。

因此需要第二个机制：**监督（monitoring）**。

最简单的做法，不是安装一套复杂设备，而是由每户取水时共同记录领取量，并定期核对水池剩余量。

| 我们观察到的情况 | 可能的解释 | 现在应该做什么 |
| --- | --- | --- |
| 某户记录为45升 | 额外需求，或违反约定 | 先询问原因，再判断 |
| 每户都记为40升，但水少了 | 水池或管道可能漏水，也可能记录有误 | 检查设施和记录 |
| 有家庭根本无法到场记录 | 参与条件存在差异 | 改进记录办法 |

这里的关键并不是「监督越严越好」。**监督本身也可能出错，而且会消耗时间、侵犯隐私，甚至产生不公平。**

更准确地说，我们需要让群体获得足够可靠的信息，能够区分*真正违反约定*与*客观条件造成的差异*。

到这一步，原来只靠口头信任的合作，出现了一个小小的运行结构：

```text
共同约定
        │
        ▼
各户实际取水
        │
        ▼
记录与核对
        │
        ▼
行为与约定是否一致？
        │
        ├── 是 ────► 继续按约定执行
        └── 不确定 ─► 检查记录、漏水或特殊需求
```

可是，即使能够确定有人故意违反约定，我们仍然没有解决下一个问题。

## 三、如果有人明知规则，却仍然不遵守呢？

假设大家已经核对记录，确认甲没有特殊原因，却多取了5升。

第一次，其他人可能只是提醒他。如果甲愿意改正，事情到此结束。

但如果甲发现：

> 「每次多取一点，最后也只是被说两句。」

那么，对某些人来说，违反约定仍然可能比遵守更有吸引力。原本愿意遵守的乙，也可能开始怀疑自己是否值得继续克制。

我们终于遇到了新的需求：**不能只有「什么是不允许的」，还要能够处理「发生了不允许的事情之后怎么办」。**

这时才需要引入**执行（enforcement）**。

执行可以有很多形式。对于这个小群体，未必一开始就需要强制处罚。可以先要求说明情况、补记用量、提醒、讨论补救办法；屡次故意违反时，再考虑事先约定、适当且可执行的后果。

一个重要区别是：**执行不是惩罚的同义词。** 它还包含纠正错误、修复损失、处理例外以及维持对规则的共同预期。

继续做一个最小的数字实验：

| 20户家庭的行动 | 当天合计取水 | 原定100升应急水还剩多少 |
| --- | ---: | ---: |
| 都按每户40升取水 | 800升 | **100升** |
| 有2户各多取5升 | 810升 | **90升** |
| 20户各多取5升 | 900升 | **0升** |

因此，问题不只是少掉几升水，更在于：**一个不被执行的规则，可能改变其他人对未来的预期，进而改变他们的行动。**

这里必须说明：上表只能证明水量上的计算结果，**不能凭这些数字证明监督或处罚必然会让人节水**。实际效果取决于信任、误判、执行成本和每户需求等条件。

## 四、让一个人负责监督，新的权力问题就出现了

到现在为止，20户家庭已经有了约定、记录和违约处理办法。

但每次由20户一起核对每条记录、讨论每起争议，十分费时。大家提出一个更省事的方案：

> 「我们选一位负责记录和协调取水的人。」

这个办法在人数不多、彼此熟悉时可能很好用。

但是，只改变一个条件：负责记录的人与甲是亲戚。

如果监督者故意漏记甲多取的5升，或者随意认定乙违反约定，其他家庭就会发现：

**把某种决定交给一个人，能够降低协调成本，却也让这个人获得了影响他人处境的能力。**

这就是我们开始理解**权力**（power）的入口。这里先采用最小定义：**一个人或组织有能力影响其他人的可选行为、资源分配或决定结果。**

但请注意，**有能力影响别人，不等于这种影响天然正当**。

如果大家同意让某人记录用水，那么这是一种有限的**授权**：群体把特定事务交给他处理。授权不意味着这个人可以随意修改取水标准，或为自己制定特殊待遇。

为了避免负责人变成不受约束的裁判，家庭们又增加了几个简单安排：

- 取水记录对相关家庭开放核对，但不必公开所有私人生活细节。
- 记录者不得自行决定对亲属的争议处理。
- 涉及额外用水或重大调整时，要有讨论和复核机会。
- 负责人需要解释决定，也可以被更换。

这些安排是**教学模型中可能采取的办法**，并不代表现实中只有这一种治理模式。

现在回头看，为什么规则不能只理解为「有个人下命令」？

因为共同治理还要面对另一个问题：**谁能决定、决定范围多大、决定错了怎么办、又由谁来纠正？**

这就是下一层政治问题的最初形态。

## 五、到这里，我们才有必要区分三种容易混淆的东西

前面推导出来的东西，现在可以放在一起比较。

| 概念 | 在共享水池中的具体表现 | 不能误解成什么 |
| --- | --- | --- |
| **规则** | 先各取40升，特殊需求需要说明 | 规则写下来就一定有效 |
| **执行能力** | 能够核对取水、处理违规与纠纷 | 只要处罚严厉就一定有效 |
| **正当性与约束** | 谁被授权处理、能否申诉、能否更换负责人 | 有控制能力就自然有正当性 |

同一个人可能同时拥有监督能力与群体认可，但这两者不是一回事。

从社会运行角度看，**稳定的规则往往不仅需要参与者知道它是什么，还需要有人相信它可以被合理执行，并且争议能够得到处理。**

但我们仍然不能从这个小水池，直接推导出某个国家必然应当采用总统制、议会制、君主制或其他政体。那些制度还涉及国家形成、历史冲突、法律安排、政治代表、强制力与权利保障等问题，后面必须另行研究。

## 六、回到历史：2018年开普敦的节水规则是怎样执行的？

我们的20户家庭只是一个帮助思考的模型。真实的开普敦则是一座人口众多、供水网络复杂的城市。

2018年1月30日，开普敦市政府公布：相关水库蓄水量约为总容量的**26.3%**，全市每日用水约**5.8亿升**，而新的目标为**4.5亿升/日**。随后，**Level 6B** 限水措施于**2018年2月1日**生效，提出**每人每天不超过50升**的用水限制。参见：[开普敦市政府公告，2018-01-30](https://www.capetown.gov.za/media-and-news/50-litres-per-day-will-help-us-to-avoid-day-zero/)。

然而，城市并非在2018年2月才突然想到「需要执行规则」。实际措施此前就已逐步展开。

**2017年8月16日：从警告走向高用水家庭的管理设备。**

开普敦市政府曾宣布，已向月用水超过20,000升的家庭发出节水警告，并开始对高用水家庭进行检查和安装用水管理设备。市政府当时说明，这些行动依托现有的**Water By-law**（水务附例）及相关指令展开，并非由检查人员任意决定。参见：[开普敦市政府公告，2017-08-16](https://www.capetown.gov.za/media-and-news/city-moves-to-restrict-high-consumption-households-with-water-management-devices/)。

**2018年2月：用水限制配合更高的收费。**

除了降低用水目标，市政府也提高了相应水费水平，让较高的用水量承担更高收费。2018年2月6日，市政府进一步解释了这项价格措施，希望借此减少需求。参见：[开普敦市政府公告，2018-02-06](https://www.capetown.gov.za/media-and-news/new-tariffs-to-encourage-50-litre-usage/)。

**制度层面：执行措施必须有依据。**

开普敦市政府对水务规定的说明指出，水务附例为限水、罚款、法律行动以及某些限制供水的措施提供法律依据。参见：[开普敦市政府：水务规定与附例](https://www.capetown.gov.za/work-and-business/commercial-utility-services/commercial-water-and-sanitation-services/know-your-water-regulations/)。

这些事实与教学模型有相似之处：

| 20户家庭的模型 | 开普敦历史中的相应做法 |
| --- | --- |
| 「每户先取40升」的共同约定 | 城市公布分级限水标准和每日用水目标 |
| 记录取水量 | 水表、用水数据及检查 |
| 违规后不能只依靠口头提醒 | 警告、收费调整、特定情况下的限流设备等 |
| 谁可以执行、依据是什么 | 市政水务附例与行政权限 |

但二者**不能直接等同**：城市的法定权力、公民权利、基础设施、社会不平等与行政程序，都远比20户家庭的共同约定复杂。

### 一个不能略过的反例：措施越严格，就一定越有效吗？

并不一定。

经济合作与发展组织（OECD）在对开普敦水治理的回顾中指出，危机期间的限水、价格及设备措施涉及多级政府和不同社会群体；有些自上而下的管理方式及对决策理由的沟通不足，影响了公众信任。参见：[OECD：Water Governance in Cape Town, South Africa](https://www.oecd.org/en/publications/water-governance-in-cape-town-south-africa_a804bd7b-en/full-report/key-water-governance-challenges-in-cape-town-south-africa_5fdbee87.html)。

学术研究也强调，开普敦不同社区的供水条件并不相同，历史形成的社会不平等影响居民面对危机的能力。参见：[Rodina, 2019：*Water resilience lessons from Cape Town's water crisis*](https://wires.onlinelibrary.wiley.com/doi/10.1002/wat2.1376)。

所以我们不能从「某户用水更多」直接推出「这户不守规则」，更不能因为政府能够执行某项措施，就自动认为每项措施都公平、必要或没有副作用。

同样，也不能把后来避免大规模断供的结果，全部归因于某一项罚款、设备或宣传。降雨、居民行为、供水系统管理等因素在现实中是相互交织的。

**历史给我们的启发不是「处罚一定有效」，而是：规则的内容、监测方式、执行能力、公众信任以及公平条件，会共同影响治理。**

## 七、试着用同一个原理解释两件生活中的事

**例子一：办公室报销制度。**

公司告诉员工「出差费用合理报销」，一开始可能已经足够。但如果员工和财务对「合理」的理解不同，争议就会不断出现。于是公司可能写明费用标准、提交票据的要求和审批流程。

可是如果审批经理能够随意给亲近的人报销，却拒绝其他员工的相同申请，那么出现的就不只是「规则不清楚」，而是**执行者的权力如何受到约束**。

**例子二：小区停车管理。**

住户都希望道路畅通，最开始靠「不要乱停车」的提醒。随着车辆增加，物业或住户组织可能划定车位、公布通道规则，并设置举报与处理流程。

但如果部分住户有残障出行需求，完全一致的停车安排未必合理。规则既要可执行，也需要处理实际差异。

这两个例子与取水并非同一种法律关系，却有相同的分析问题：

**规则写清楚了吗？如何知道实际情况？谁来处理违约？处理者受到什么限制？**

## 八、一个小实验：你会怎样改进这套规则？

回到20户家庭。假设大家已经委托甲负责登记取水。

一天，乙家比平常多取了10升。甲准备立即处罚，但乙说明家里有人需要额外照护。

先不要急着判断谁对谁错。试着回答：

1. 如果只看取水记录，我们真正知道了什么，又不知道什么？
2. 如果完全不调查就处罚乙，会带来什么风险？
3. 如果任何人只要说「有特殊情况」就可以多取，规则又会面临什么问题？
4. 谁应该决定特殊用水的安排？负责登记的甲是否应当拥有最终决定权？
5. 如果甲的决定存在偏袒，乙可以通过什么办法要求重新核对？

这些问题的答案可能因群体规模、紧急程度和当地法律而不同。但你已经能够发现：**真正的治理问题，不只是制定命令，而是建立处理信息、冲突和权力的可靠过程。**

## 九、回看：这一章的设计是怎样一步步长出来的？

我们没有从「法律」「政府」「政体」这些术语开始。

起点只是**20户家庭想保留100升应急水**。

```text
共同水池：希望保留100升
        │
        ▼
口头约定：每户先取40升
        │
        ▼
有人超额：约定没有自动实现
        │
        ▼
明确规则：谁在何时可以取多少
        │
        ▼
无法判断：记录与核对
        │
        ▼
确认违约：需要适当处理
        │
        ▼
委托负责人：出现新的决策权
        │
        ▼
可能偏袒：需要复核、解释与更换机制
        │
        ▼
形成可持续的共同治理安排
        │
        └──► 反馈：执行经验推动规则修改，回到「明确规则」
```

每增加一个环节，都有前一个简单方案解释不了的问题：

- **口头提醒**不够明确，于是出现可判断的规则。
- **写出规则**不能告诉我们是否遵守，于是需要记录与监督。
- **知道违反规则**不等于问题已解决，于是需要适当执行。
- **委托一个人执行**可能产生偏袒，于是需要授权边界与纠错机制。

这就是从人际合作逐步走向社会制度的一个**可能的因果路径**。它可以帮助我们理解制度的功能，却不能单凭这段推导证明国家在历史上就是这样产生的。

### 本课最底层的结论

> **当人的行动相互影响时，共同目标不会自动转化为共同结果。规则需要让行为可以被预期、判断和协调；而一旦有人拥有执行规则的权力，就必须继续追问这种权力的来源、边界与纠错方式。**

把它放进现代社会，可以理解公司内部为什么需要审批、社区为什么需要公共约定、政府执行政策为什么离不开行政能力，以及为什么政治制度还必须回答「谁能决定」与「谁监督决定者」。

但我们此时只研究了**怎样维持共同约定**，尚未回答另外一个问题：**为什么这20户家庭一开始就有权使用这座水池？如果有人拥有水池旁的土地，他能不能独占所有水？**

这不是简单增加一条规则就能回答的问题。

它将引出第五课：[**《谁有权使用资源？——从共同取水到权利、产权与利益分配》**](./world-05-who-has-the-right-to-use-resources.md)。
