# 为什么需要货币？——从统一计价，到支付与信用的起点

> **系列位置：** 第 4 层「社会基本机制」· 第 9 课  
> **本课只回答一个问题：** 当分工和交换越来越复杂，**人们怎样用共同的尺度比较交易，并在不同的人和时间之间完成支付？**  
> **上一课：** [为什么会出现市场与价格？——从逐户讨价还价，到分散信息的协调](./world-08-why-markets-and-prices-emerge.md)  
> **系列引言：** [从根本理解世界：社会运行原理的总框架](./world-introduction.md)

上一课，我们的村庄从20户发展到200户，开始在公告板上公开报价。比如：**1把普通锄头换8千克粮食**。买卖双方可以通过报价、库存与成交情况调整自己的计划。

但是村里不只有粮食和锄头。

有人卖盐，有人修屋顶，有人维护输水管线，还有人提供运输服务。农户甲每次买东西都要问：

- 一把锄头换几千克粮食？
- 一袋盐换几把锄头？
- 修一次管线需要多少粮食、多少盐，还是直接帮忙劳动一天？

我们已经知道**价格能帮助协调交换**。但现在的新问题是：**各种价格使用的尺度不同，怎样把它们放到一起比较？**

这次，我们不从纸币、金币或中央银行讲起。我们先只解决一个更小的问题。

## 一、最简单的办法：每两种商品都单独约定交换比率

假设村庄现在只有三类可以交易的成果：粮食、锄头、管线维修服务。

大家完全可以分别记下：

| 交换对象 | 一种可能的约定（教学假设） |
| --- | --- |
| 锄头 ↔ 粮食 | 1把锄头 = 8千克粮食 |
| 维修服务 ↔ 粮食 | 修一次管线 = 8千克粮食 |
| 锄头 ↔ 维修服务 | 1把锄头 = 修一次管线 |

对三类商品，这样做没什么大问题。人们可以根据质量、时间和不同家庭的需要，随时重新谈条件。

但是假设商品和服务增加到30种，如果希望把**任意两种商品之间的比率**都分别公布出来，最多就需要：

`30 × 29 ÷ 2 = 435`

种成对比较。

这个数字只是一个**组合计数**：它不意味着每个真实市场每天都必须公布435个价格，也不意味着现实里每种物品都能直接换到另外一种。但它提示了一个问题：**商品越多，逐对表达和比较的工作越繁重。**

即使存在这些报价，新的交易条件仍会不断变化。如果维修服务需要特殊材料，今天和下周的价值也可能不同。

我们真正缺少的，或许不是某一种新的物品，而是一个**大家都能读懂的共同尺度**。

## 二、第一次改进：所有商品都用同一种单位报价

村里的记录员提出一个很朴素的办法：

> “先不要争论拿什么实物付款。为了便于比较，我们暂时用『1千克粮食的参考价值』作为一个记账单位。”

我们将这个单位简称为 **1个计价单位**。它只是村里约定的一种**衡量尺度**，不是一张纸币，也不代表有一袋粮食真的被存进仓库。

现在公告板变成这样：

| 商品或服务 | 公告板上的参考价格 |
| --- | ---: |
| 粮食1千克 | 1单位 |
| 普通锄头1把 | 8单位 |
| 盐1袋 | 4单位 |
| 修水渠一次 | 8单位 |

农户甲想用盐换锄头。过去，他得询问对方愿意接受几袋盐；现在，他至少可以从公告板判断：在这些参考价格下，一把锄头与两袋盐标出的价值相等。

当然，**参考价值相等不代表任何卖家都愿意成交**。盐的质量、锄头的稀缺程度、交货地点及双方的实际需要，仍然会影响是否交易。

但我们已经获得一种新能力：不同商品可以用一个共同尺度**记录、比较、核算**。

这时，才有必要引入第一个新概念：

**计价单位（unit of account）**，就是人们用来表达商品价格、债务金额和会计记录的共同尺度。

```text
三种商品：少量交换比率，还能逐个比较
        │
        ▼
三十种商品：成对比较越来越繁琐
        │
        ▼
引入同一个计价单位
        │
        ▼
商品和服务的价格可以放在同一张账上
```

这里先停一下，检查我们究竟解决了什么。

**解决了：** 更方便地比较商品、计算收入和成本、记录谁欠谁多少。

**没有解决：** 某个人答应支付“8单位”，究竟拿什么给对方？

这就把我们带到下一层。

## 三、计价不是支付：写着“8单位”，不等于手里真有可以交付的东西

还是同一个村庄。农户甲有粮食，需要一把锄头；工具匠乙有锄头，但他现在最需要的不是粮食，而是**修理自家的供水管**。

甲对乙说：“这把锄头值8单位。我给你8千克粮食。”

乙回答：“我知道价值是8单位，但我现在粮食够吃，更需要维修服务。”

**双方同意价格，却仍然没有成交。**

如果维修工丙正好需要粮食，大家可以安排一笔三方交易：

1. 甲把8千克粮食交给丙；
2. 丙给乙修一次管线；
3. 乙把锄头交给甲。

三个人互相协调，交易就可能完成。

```text
农户甲 ── 粮食 ──────► 维修工丙
维修工丙 ── 维修服务 ──► 工具匠乙
工具匠乙 ── 锄头 ─────► 农户甲
（三条边首尾相接，每个人付出的正是自己擅长的东西）
```

但这个办法又暴露出限制：如果丙今天不需要粮食，或者维修要等两周，三个人就需要重新协商。商品越多、交易越频繁，找到这种相互匹配的组合就越麻烦。

于是我们发现，**共同的计价尺度虽然有帮助，但还缺少一种容易被别人接受、可以在交易之间转手的支付媒介。**

### 第二次改进：用大家普遍接受的东西完成支付

假设村里的许多交易者愿意接受某种标准化的凭证，并相信以后也能用它向别人购买商品。

甲卖粮食时先收取这种凭证；之后，他就可以用凭证向乙买锄头。乙不需要当场接受粮食，只要相信自己能再把凭证交给其他人。

注意，我们并不是说村里突然凭空印一张纸，大家就必然会相信它。要让它实际发挥作用，至少需要考虑：

- 谁有资格发行凭证？
- 凭证能否被重复伪造、任意增发？
- 别人为什么愿意继续接受它？
- 如果承诺无法兑现，损失由谁承担？

这里我们先把信任和发行机制当作**尚未解决的条件**，不在本课假装已经解决。

现在，才有必要引入第二个概念：

**交换媒介（medium of exchange）**，就是人们愿意在交易中接受、并可继续用来交换其他商品和服务的东西。

它与计价单位的功能不同：**计价单位回答“值多少”，交换媒介回答“拿什么完成交易”。** 现实中，两种功能常由同一套货币体系承担，但逻辑上可以区分。

## 四、交易不在同一天完成，新的问题又出现了

村里的管线维修工丙接到一个任务：今天修完水渠，但下个月收报酬。

如果按现在的条件直接交换，丙需要相信对方下个月确实会交付约定的粮食，或者其他双方接受的支付物。

他们可以写下一张欠条：

> “甲欠丙8个计价单位，约定30天后清偿；具体清偿方式另行约定。”

这张纸至少做了两件事：**记录金额**和**记录未来履行承诺的义务**。

但它不自动变成货币。

假设丙去买盐，盐商丁说：“甲是谁？我不认识他，也不知道他到期会不会还款。”

丁不接受这张欠条，交易又卡住了。

**一项私人债权，可以对当事人有价值，却不一定能被整个村庄普遍接受。**

如果大家经常延期交货、延期支付，就会逐渐需要账簿、信用记录、履约安排，以及处理不履约的规则。但这些制度具体怎样形成，要看当地的法律、组织和历史环境。

这个新机制叫**信用（credit）**：在本课的最简单情形中，一方允许另一方在未来履行约定的支付义务，双方之间形成债权债务关系。

信用不是货币的同义词，二者却密切相关。

```text
用共同单位报价
        │
        ▼
仍然不能保证交易即时完成
        │
        ▼
普遍接受的媒介：帮助完成支付
        │
        ▼
交货与付款时间不同
        │
        ▼
欠条与账簿：记录未来支付承诺
        │
        ▼
问题：私人承诺为什么能被第三人接受？
```

到这里，已经可以看到下一课的入口：**信用关系为什么能够扩大交易，也为什么可能引发违约和连锁风险？**

## 五、如果今天收到的钱要明年才花，它还得解决什么问题？

现在，甲卖掉一批粮食，获得了一笔村里普遍接受的支付媒介。

但他想等半年后再购买工具。

这时候，他会关心：半年以后，手中的支付媒介还能买到多少东西？

如果这种媒介容易腐烂、损坏，或者被大量发行而使人不再相信它，甲就可能不愿长期持有。

因此，一种货币安排还需要在一定程度上帮助人们**把购买力从现在带到未来**。

经济学通常把这称为**价值储藏手段（store of value）**。它不表示货币能够永远保值。现金会受通货膨胀影响，某些货币在危机中可能大幅贬值；其他资产也可能更适合长期储蓄。

所以，我们现在有了研究货币的三个不同角度：

| 功能 | 它回答的问题 | 村庄中的最小例子 |
| --- | --- | --- |
| 计价单位 | 东西值多少？ | 锄头标价8单位 |
| 交换媒介 | 交易怎样支付？ | 卖粮食后拿可流通凭证买锄头 |
| 价值储藏 | 购买力怎样跨时间保留？ | 今天收款，半年后再消费 |

这三种功能是国际货币基金组织和英格兰银行讨论货币时采用的常见分析方式。它们可能由同一套货币制度共同承担，但某个工具有其中一种功能，并不表示它就具备全部功能。[^imf-money][^boe-money]

## 六、历史验证之一：古代两河流域的账簿，比我们的“先有金币”想象更早、更复杂

前面是**教学假设**。现在换到真实历史，检查人类是否真的沿着「物物交换 → 统一价格 → 某种凭证 → 货币」这一条固定道路走过来。

答案是：**不能这么断言。**

纽约大都会艺术博物馆收藏了一块约公元前**3100—2900年**、来自美索不达米亚地区的泥板。馆方说明，这块泥板很可能记录了大型神庙分配谷物的情况，其中使用了表示物品和数量的记号。[^met-tablet]

这件文物非常重要，因为它至少证明：

- 很早的社会就需要记录**数量和资源分配**；
- 记账不只是为了街头买卖，也可能服务于神庙等**大型组织的管理**；
- 从这些记录**不能直接推出**当时人人使用同一种金币、现金交易十分普遍，或所有交易都按我们村庄的步骤出现。

我们刚才通过村庄推导出“共同尺度有助于复杂协作”，而泥板提供的是另一类现实证据：**在真实历史中，组织管理与记账已经有非常悠久的历史。**

再看一件时间晚得多的文物。大英博物馆收藏了一块**新巴比伦时期**的泥板，馆藏说明它记录的是一笔**白银贷款**。这说明，在那个具体历史环境中，借贷和书面债务记录也已存在。[^britishmuseum-loan]

请不要把这两块相隔两千多年左右的泥板拼成一条未经证明的“必然演进史”。它们分别支持两件事：古代组织存在记账，古代社会也存在债务安排。具体历史路径必须由更多同时代材料研究。

一些经济史与人类学研究对教科书常用的“先有普遍纯物物交换，后来人们为解决交易困难而发明货币”的叙事提出过批评。国际货币基金组织发表的研究也专门讨论过这种起源解释的证据问题。[^imf-origin]

因此，**本课推导的是“某种制度能解决什么问题”，不是“它在历史上必定先于什么、后于什么”。**

## 七、历史验证之二：你今天在超市扫码付款，究竟发生了什么？

回到现代生活。

你在超市看到一瓶水标价**3元**，随后用手机或银行卡支付。

这里其实涉及几个不同的层次。

**第一，标价。** “3元”是用统一的货币单位表达价格。无论你用现金、刷卡还是其他方式支付，货架价格都可以用同一个单位比较。

**第二，支付指令。** 扫码或刷卡本身通常不是“凭空制造了3元钱”。它更多是在某个支付安排下发出指令，由相应账户、支付机构或银行体系完成扣款与收款。不同产品的账户法律关系和资金流转方式可能不同，不能把所有钱包余额都简单等同于一种银行存款。

**第三，支付背后的资金。** 现代社会里，公众持有的货币很大一部分不是纸钞，而是银行账户上的存款。英格兰银行2014年的解释强调，银行存款属于商业银行对存款人的负债，而商业银行发放贷款时通常也会创造相应存款。[^boe-money][^boe-creation]

这件事暂时不用完整理解——它是后续银行课程的主题。现在只需要看清楚：

> **手机是支付工具，银行存款可能是被转移的货币资产，人民币或英镑则是价格和会计记录使用的计价单位。**

把三者混在一起，就很容易误以为“二维码就是钱”，或者“钱只能是纸币和硬币”。

```text
商品：一瓶水
        │
        ▼
标价：3元
        │
        ▼
选择支付方式：现金 / 刷卡 / 扫码
        │
        ▼
按相应支付安排完成清偿
        │
        ▼
商家确认收款并交付商品
```

这张图只展示买卖过程中的**业务顺序**，不是银行卡或移动支付清算系统的完整技术流程。各支付工具之间的差异，后面需要单独研究。

## 八、为什么大家接受同一种货币？信任到底来自哪里？

现在可以把问题追得更深一点。

一张纸币的材料本身，可能远没有它所标示的金额那么有价值；银行存款更不会以一袋袋硬币的形式放在某个账户里。

那人们为什么愿意接受？

在真实经济中，这种接受依赖多种互相作用的条件：

- 人们预期**其他人未来也会接受**这种货币；
- 法律制度明确债务、支付与契约的规则；
- 税收和公共支付制度能形成对某些计价与支付安排的持续需求；
- 银行体系、支付网络和监管影响日常支付能否稳定完成；
- 货币购买力的稳定程度影响人们愿意长期持有多少。

这些因素不是一张“只要具备其中一项就能成功”的配方。不同国家、时代与货币制度的组合并不相同。

从我们目前的模型看，最根本的一点是：

**货币的作用依赖社会中的接受关系。你愿意今天收到它，部分原因是你相信明天还能用它做事。**

但有接受关系不等于完全没有风险。历史上也有支付体系失灵、货币剧烈贬值或机构无法兑现承诺的情况。为什么这种信任会建立、怎样被制度支持、又如何崩溃，是后续金融与国家治理课程要回答的问题。

## 九、一个能自己做的小实验：把“标价”和“付款”分开

仍然使用本课**假设的200户村庄**。

公告板上规定：

| 物品或服务 | 参考价格 |
| --- | ---: |
| 1把锄头 | 8单位 |
| 1袋盐 | 4单位 |
| 1次水渠维修 | 8单位 |

现在有三个人：

- 甲有1把锄头，想换2袋盐。
- 乙有2袋盐，但不需要锄头；他需要维修水渠。
- 丙能提供1次维修服务，但他只愿意收可靠的、自己能够继续使用的支付物。

请尝试判断：

1. **只把所有东西换算成单位**，能保证三个人立即成交吗？
2. 如果甲给丙写一张“欠8单位”的欠条，丙为什么可能拒绝？
3. 如果全村大多数交易者都长期接受同一种凭证，这种凭证解决了哪一个困难？
4. 假如该凭证突然可以不受限制地大量发行，你认为人们继续接受它的意愿可能怎样变化？为什么？

<details>
<summary>展开参考分析</summary>

**1. 不能。** 共同计价解决了“怎么比较”，没有解决“拿什么支付，以及对方是否愿意接受”。

**2.** 因为欠条代表特定人的未来承诺。丙未必相信甲会履约，也未必能把甲的欠条交给其他人。

**3.** 它可以把“先找到正好想要自己商品的人”变成“先把自己的成果换成别人广泛接受的媒介，再去购买需要的东西”，减轻交易对象和时间必须完全匹配的困难。

**4.** 如果发行过多使购买力不稳定，或让人怀疑发行者能否履行其承诺，人们可能降低持有和接受意愿。但具体影响还取决于发行机制、需求、产出、规则和预期，不能只看发行数量得出单一结论。

</details>

## 十、回看这次从小问题长出了什么机制

```text
上一课：市场中出现不同商品的报价
        │
        ▼
难题一：几十种商品难以逐对比较
        │
        ▼
最小改进：共同计价单位
        │
        ▼
难题二：标价相同不代表付款能完成
        │
        ▼
最小改进：广泛接受的交换媒介
        │
        ▼
难题三：交付和支付不在同一天
        │
        ▼
最小改进：账簿、欠条与信用关系
        │
        ▼
新问题：谁保证承诺可靠？怎样处理违约？
```

这张图只呈现**本课的分析与教学路径**。并不是宣称人类历史真的经历了以上各步骤，更不是说货币一定起源于纯物物交换。古代账簿、公共权力、债务与不同形式的支付手段可能在历史中相互塑造。

现在，我们可以把本课得到的底层原理压缩成一句话：

> **当社会分工让人们越来越依赖陌生人的商品和劳动时，复杂交易不仅需要一个比较价值的共同尺度，还需要能被广泛接受的支付安排；而交易一旦跨越时间，就会涉及承诺、信用与信任。**

这也让我们第一次看见：**货币不只是“某种有价值的东西”，更是一组社会能够共同计价、支付和跨时间安排交易的制度关系。**

它既能帮助交易，又不能单靠自身保证公平、购买力稳定或金融安全。

村庄已经能够用统一单位报价，许多交易也能通过共同接受的支付媒介完成。

如果施工者现在缺少资源，却承诺未来偿还，我们怎么判断承诺可信？借款人为什么愿意付出额外代价？一旦几个人同时违约，又会发生什么？
